# Immersive Interior Designing

Unity project for interior design / first-person interaction work.

## Requirements

- Unity `6000.3.13f1`

## Open Project

1. Clone the repository.
2. Open Unity Hub.
3. Add the cloned folder.
4. Open it with Unity `6000.3.13f1`.

## Repository Structure

- `Assets/`: scenes, scripts, prefabs, audio, and game content
- `Packages/`: Unity package dependencies
- `ProjectSettings/`: Unity project settings

## Collaboration Notes

- Commit both asset files and their `.meta` files.
- Do not commit `Library/`, `Temp/`, `Logs/`, or generated `.csproj` / `.sln` files.
- Pull the latest changes before starting new work.
